Kangju Workspace Bridge

A private, single-user integration with Google Workspace.

What this application does

Kangju Workspace Bridge is a personal automation tool that connects a self-hosted assistant to one Google account, so that its owner can manage their own email, calendar and documents through a command-line and messaging interface instead of clicking through the web UI.

Who uses it

Exactly one person: the owner of the Google account that grants access. It is not offered to the public, there is no sign-up, no multi-tenant service, and no other user can authenticate to it. It exists purely to automate its owner's own account.

What it does with your Google account

  • Gmail — read and search mail, and create draft replies for the owner to review and send manually.
  • Google Calendar — read and create the owner's own calendar events.
  • Google Drive — find and upload files to the owner's own Drive.
  • Sheets and Docs — read and write spreadsheets and documents the owner asks it to work on.
  • Contacts — look up the owner's contacts when addressing mail.

Every action is initiated by the owner, in the owner's own session, against the owner's own data. The application never sends mail, shares files, or modifies anything external without an explicit instruction from the owner.

How your data is handled

Data is processed and stored only on the owner's own self-hosted machine. OAuth credentials are kept in a local file readable only by the owner's operating-system account. Nothing is transmitted to any third party, there is no analytics, no telemetry, and no external server operated by this application. See the Privacy Policy for the full detail.
